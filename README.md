# Projeto-Anime :tv:
![Badge em Desenvolvimento](http://img.shields.io/static/v1?label=STATUS&message=EM%20DESENVOLVIMENTO&color=GREEN&style=for-the-badge)

Bem-vindo ao meu primeiro projeto de front-end! 🚀  
Este projeto foi desenvolvido utilizando apenas **HTML5** e **CSS3**, com o objetivo de praticar a criação de páginas web, estruturação de conteúdo e estilização visual.

---

## 📌 Sobre o Projeto

O projeto consiste em uma interface web simples e responsiva, criada para aplicar conceitos básicos de desenvolvimento front-end, como:

- Estrutura semântica com HTML
- Estilização com CSS
- Organização de layout
- Responsividade básica
- Boas práticas de desenvolvimento

## 🚀 Como Executar o Projeto

1. Clone este repositório:

```bash
git clone https://github.com/phFonseca/Projeto-Anime.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto-Anime
```

3. Abra o arquivo `index.html` no navegador.
